# 00 - Introducción a Veltrion Framework

Veltrion Framework es un ecosistema de desarrollo empresarial en PHP 8.x diseñado bajo el paradigma de Clean Architecture, Domain-Driven Design (DDD) y aceleración mediante Inteligencia Artificial local y agentes autónomos.

## ¿Por qué Veltrion PHP?
- **Separación de Responsabilidades**: El dominio de negocio no depende de frameworks HTTP ni de controladores de base de datos.
- **Productividad RAD**: Generación automatizada de entidades, repositorios, casos de uso y vistas mediante la CLI.
- **Auditoría Multiagente**: Agentes integrados en Python para evaluar calidad, seguridad (SAST), experiencia de usuario y reglas de negocio.
- **IA Local Integrada**: Asistencia por lenguaje natural con Ollama sin exponer datos ni código a servicios de terceros.
